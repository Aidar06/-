# Дария 1 жаш — Тушоо Той чакыруу сайты 🌸

Кыздын 1 жашына жана Тушоо тоюна арналган интерактивдүү, роза түстүү минималистик React чакыруу сайты.

## 🚀 Өзгөчөлүктөрү

- ✉️ **Интерактивдүү Конверт Ачуу**: Эки тарапка жылган сургуч мөөрлүү №1 конверт анимациясы.
- ⏱️ **Реалдуу убакыт Таймери & Календарь**: 15-ноябрь 2026-жыл саат 15:00 убактысына карай эсептеген таймер жана Ноябрь 2026 календары.
- 📜 **Той программасы (Timeline)**: Мобилдик телефондорго 100% адаптацияланган тушоо кесүү программасы.
- 👗 **"ЭТНО стиль" Дресс-код**: Кыргыз улуттук оймо-чиймелери жана жумшак түстөр палитрасы.
- 📍 **Мекен-жайыбыз**: "Алтын казына" рестораны (Победа пр. 351), Google Maps, Yandex Maps жана 2GIS навигациялары.
- 🎶 **Фондук Музыка**: Интерактивдүү үн кнопкасы жана майрамдык күү.

## 🛠 Технологиялар

- **React 18 / 19**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **Canvas Confetti**
- **Lucide Icons**

## 💻 Иштетүү (Getting Started)

```bash
# Клондоо же папкага өтүү
cd dariya-tushoo-toy

# Керектүү пакеттерди орнотуу
npm install

# Проектти локалдык режимде иштетүү
npm run dev
```
